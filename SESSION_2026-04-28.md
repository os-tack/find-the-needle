## Trust gate — the bar a sweep must clear

**Before kicking off a multi-bench multi-model sweep, the following must be verifiable on a single cell:**

1. The cell's `cost_usd` is non-zero and matches an expected ballpark for that model's pricing
2. The cell's `wall_clock_ms` is decomposed into (build / install / boot / agent / test) phases
3. The cell's `resolved=true/false` survives running the same scenario twice in a row
4. Re-running the same (model, arm, bench) cell N=3 times yields ≥66% agreement on resolved
5. A `claude-haiku-4-5 / null-pointer-config / kernel` cell completes with documented per-turn tokens, cost, tool_uses

Until that gate passes, scores are infra-validation data, not benchmarks.
